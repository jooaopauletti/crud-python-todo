# 📝 CRUD Python - To-Do List
Aplicação de lista de tarefas desenvolvida em Python, executada via terminal.

## Funcionalidades
- ✅ Adicionar tarefas
- 📋 Listar tarefas
- ✏️ Atualizar tarefas
- ❌ Deletar tarefas
- 💾 Dados salvos em arquivo JSON

## Como executar
1. Clone o repositório
2. Execute o arquivo `main.py`

```bash
python main.py
```
## Tecnologias
- Python 3
- JSON
